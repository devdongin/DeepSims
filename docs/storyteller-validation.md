# #89 사건 페이싱 검증

schema62/logic58. 일일 질병·화재의 기존 위험 드로우 수와 순서를 유지해 로컬 후보를 만든다.
후보가 있으면 최소2일 간격, 직전 사건 대상의 회복, 최근7일 최대3회 조건을 확인한다.
FNV 해시의 고정 문자열 순서로 최대1개를 적용하며 신규 RNG draw는 없다. 전염·진료·소방·
자연 회복은 디렉터가 변경하지 않는다. 확률 후보가 없으면 사건을 강제로 만들어내지 않는다.

최신 main ac12282 통합 후 전체 회귀 419/419, 프로덕션 빌드 통과. 별도 회귀는 간격 경계·회복·최근 밀도·후보 입력 순서
불변·부에 독립적인 선택·드로우 수 보존·14일 링·v61 이관·저장 후 재생을 검증했다.

## 기본 세계 30일 A/B

seed8900, 입력 없이43,200tick. 최신 main을 기준으로 기존 독립 사건과 디렉터 양쪽 모두 발병16·회복16·굶주림42,
최종 인구31·현재 감염0이었다. 디렉터는 day16/21/28의 질병 후보를 각각1개 적용했고 나머지28회
일일 평가에는 후보가 없었다. 이 시드에서는 간격 제한이 발동하지 않았으므로 효과가 있었다고
과장하지 않는다. 43,200tick은 day30 시작 평가를 포함해 일일 평가31회다.
