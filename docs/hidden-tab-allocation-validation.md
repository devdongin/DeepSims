# #143 숨은 탭 할당 검증

## 계약

- 숨김 알림을 확인한 소켓에는 `tickBatch`를 보내지 않는다.
- 같은 시간 보이는 다른 소켓에는 배치가 계속 도착하고 세계 틱도 진행한다.
- 복귀 알림 뒤에는 직전 메시지의 다음 seq로 최신 전체 snapshot이 도착한다.
- 시뮬레이션 입력·RNG·저장 상태는 변경하지 않는다.

`test/hidden-client-http.test.js`는 두 WebSocket을 실제 서버에 연결해 위 세 항목을 함께
검증한다. 기존 `test/center-http.test.js`는 입력 사건과 수동 리싱크가 계속 동작하는지
확인한다.

## 브라우저 30분 계측

localhost:3000과 실제 플레이 DB는 사용하지 않는다. 별도 포트43143, 별도 DB, 배속48에서
`?diag=1&stream=paused`로 숨김과 동일한 서버 프로토콜을 고정한다. 인앱 자동 브라우저는
비선택 탭도 `document.hidden=false`라고 보고하므로 실제 Page Visibility 연결은 위 통합
테스트가 담당하고, 이 계측은 배치가 끊긴 실제 렌더러의 힙·객체 평탄성을 담당한다.

| 시점 | heapMB | simSprites | tweens | displayList | feed |
|---|---:|---:|---:|---:|---:|
| 시작 | 72.9 | 11 | 0 | 1501 | 0 |
| 30분 12.9초 | 75.7 | 11 | 0 | 1501 | 0 |

초기 에셋 로드가 끝난 시각 `1788455740467`ms를 기준선으로 삼아 `1788457553322`ms까지
1,812,855ms(30분12.9초) 측정했다. 힙 기울기는 `(75.7-72.9)/30.21425 = +0.093MB/분`으로
허용선 `+10MB/분` 미만이다. `tileCmds=8395`, `props=246`, `roads=1010`, `gardens=231`,
`simSprites=11`, `displayList=1501`, `tweens=0`, `feed=0`도 시작과 종료가 모두 같았다.
GC 시점에 따른 힙 변동과 별개로 렌더 객체 누적은 관찰되지 않았다.
