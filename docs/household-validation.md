# #51 가구 모델 검증

schema59/logic55. 구 세이브는 주민의 현재 집에서 `householdId`를 만들고 결혼한 쌍은 두 ID를
오름차순으로 합친다. 기존 주민·집·돈·관계·RNG 상태를 새로 만들거나 소급 변경하지 않는다.

성인 자녀 후보는 실제 부모와 같은 집, 19세 이상, 학생·아동 제외 유급 직업, 준비금 2,400원,
빈 주택을 7일 연속 만족해야 한다. 생성된 의도는 다음 tick까지 저장되며 조건을 전부 재검증한다.
성공 시 빈집 하나로 이동하고 새 가구 ID를 얻는다. 실패 시 이동·돈 생성 없이 안정 기간을
초기화하고 `person_missing`, `household_changed`, `parent_not_cohabiting`, `income_unstable`,
`reserve_short`, `no_vacant_home` 중 하나를 기록한다. 후보·의도·집 선택은 모두 ID 순이고 RNG
드로우는 없다.

집중 검사는 안정 기간과 다음-tick 성공, 준비금 소실 실패, 룸메이트/학생 제외, 빈집 부재,
가구별 주민·부모·파트너·현금·예상 소득·고용·침대 집계, 클라이언트 투영, v58 결정적 이관을
검증한다. 최신 main 재배치 후 전체 회귀 382/382와 프로덕션 빌드가 통과했다.

고정 시드51051을 입력 없이 525,600틱(365일) 실행한 결과 인구36→227, 가구147이었고
자연 발생 분가 후보는 0건이었다. 이 세계에서는 기존 자녀가 1년 안에 19세 조건까지 자라지
않아 `created/applied/failed=0/0/0`이며 학생 이동도 0건이다. 따라서 자연 관측을 만들려고
나이·관계·돈을 조작하거나 문턱을 낮추지 않았다. 실제 성공/실패 증거는 명시적 fixture에서
7일 조건을 2일로 축소해 다음 tick 이동, 준비금 소실 실패, 저장/재개 동일 적용을 검증한다.
