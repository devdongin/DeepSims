# 에셋 생성 규칙 (Codex 전담)

> 사용자 상시 지시: **새로운 오브젝트가 필요할 때는 항상 Codex에게 에셋 생성을 요청한다.**
> 이 문서의 규칙은 모든 신규 건물 에셋에 예외 없이 적용된다.

## 필수 규칙

### 1. 내부(컷어웨이)를 반드시 함께 설계한다
클릭하면 지붕이 걷히고 내부가 보이는 §17.19 내부 모드가 있으므로, 외형만 만드는 건물은 미완성이다.
- 파일명: `bld_<type>_int.png`
- 구도: **지붕 제거 + 허리 높이 낮은 벽 + 바닥·가구가 훤히 보임**
- 외형과 **같은 건물임이 느껴져야 함** — 벽 색·창틀·소재·간판 일치
- 내부 가구는 그 시설의 자원(resources)과 대응: 집=침대, 카페=테이블, 공장=작업대 등

### 2. 쿼터뷰 4방향 회전 에셋을 만든다
§18.T2 건물 회전(dir 0~3)이 있으므로 한 방향만 만들면 회전 시 어색해진다.
- 파일명: `bld_<type>.png`(dir 0, ↙) + `bld_<type>_d1.png`(↘) + `_d2.png`(↗) + `_d3.png`(↖)
- **문이 보이는 면이 회전 규칙과 일치**해야 함: d0 남벽 / d1 서벽 / d2 북벽 / d3 동벽
- 같은 건물을 90°씩 돌려 본 모습 — 지붕 경사·창 배치·간판 위치가 일관되게 회전
- 회전 시 발자국이 스왑되는 타입(w≠h)은 그림 비율도 그에 맞게

### 3. 공통 규격
- 아이소메트릭 3/4 뷰, 16비트 SNES풍 도트(스타듀 계열), 진한 외곽선
- **플랫 마젠타 #FF00FF 배경**, 그림자 없음(클라가 타원 그림자를 그림)
- 건물 1254×1254 내외 / 지형 타일은 아이소 다이아몬드 512×256(2:1)
- 창문에 따뜻한 불빛(야간 변형이 있으면 `_night` 접미)

## 파이프라인 (Claude 담당)
1. `tools/chromakey.js` — 코너 플러드필로 마젠타 제거
2. `sips -Z 512`(건물) / `-z 64 128`(타일, **트림 금지** — 격자 정합)
3. `tools/trim-prop.js` — 건물·소품만 투명 여백 크롭(스케일 정합)
4. `client/public/props/`로 배치 → 클라 `BLD_TYPES`·`BLD_OF_FACILITY`·내부 로드 목록에 키 추가

## 발주 체크리스트
새 건물 타입 하나당 최소 **5장**을 요청한다:
`bld_X.png`, `bld_X_d1.png`, `bld_X_d2.png`, `bld_X_d3.png`, `bld_X_int.png`

> 기존 자산 중 이 규칙을 아직 못 갖춘 것(회전 3방향이 없는 건물 다수)은 배치 큐에 누적해
> 순차 보강한다 — 새 건물은 처음부터 규칙을 지킨다.
