# 제안: 평가 평균 5.5 → 9.0 (Opus 구현용 로드맵)

**성격**: 제안서. 이 문서는 구현하지 않는다. 각 항목은 Opus가 그대로 집어 들 수 있게
*파일·함수 / 완료 기준(측정 가능) / 테스트 / 예상 점수 영향*으로 적는다.

## 0. 전제

- "9점" = `docs/REVIEW_RUBRIC.md` 8항목 **평균 9/10** (★4.5급). 현재 3차 플레이테스트
  (5인) **5.5/10, ★2.5**, "게임으로서 계속" **0/5**.
- 세 회차의 공통 진단은 한 문장이다: **엔진은 진짜인데(결정성 리플레이 해시 일치, 재시작
  후 세계 연속) 플레이어가 보는 창(상단바·피드·패널)이 거짓말을 하거나 안 열린다.**
  따라서 점수를 올리는 길은 시뮬 기능 추가가 아니라 **창 수리 → 게임화 → 설명 → 마감**
  순서다. 순서를 바꾸면 안 된다: 창이 거짓말하는 동안 넣는 기능은 아무도 못 본다
  (§22.22 재정 검토가 정확히 그렇게 됐다 — 있는데 아무도 못 봤다).
- 지켜야 할 계약: §0.1(지표 조작 금지, 행동 추가로 해결), 결정성(`state[t]=simulate(state[t-1],inputs[t])`,
  클라 변경은 tick 결정적, `sim/` 변경은 Codex 합의 + 해시 테스트), 새 건물 = 5장 에셋.

## 2. 단계 — Tier 0: 거짓말 멈추기 (창 수리)

**T0-2 온보딩 성씨** — `sim/tick.js:577-579`가 `p.surname` 없으면 `surnameFor()`로 강제 부여하는데

**T0-3 상단바 레이아웃** — `client/index.html:15-17` `#clock`이 `position:absolute; left:50%`로 흐름에서 빠져

**T0-4 피드 신호/잡음 분리** — 전원 5명 불만 1순위. '공사 돕기 시작/완료'가 매시 같은 심이 즉시 쌍으로 도배

## 3. Tier 1: 게임이 되게 하기

*재미 4.2가 최저인 이유는 두 가지다 — 당길 레버가 없고, 따라갈 인물이 없다.*

**T1-1 첫 3줄 + 첫 목표 카드** — 접속 직후 오버레이: "당신은 해솔마을 시장입니다 / 국고 −10,459원, 공무원 3명이
임금을 못 받고 있습니다 / 🏛️에서 세율을 만져 보세요". 첫 정책 변경 후 카드 소멸. 2인 명시 + 2인 사유 지적.
- 완료 기준: 신규 세계 첫 접속 시 1회 표시, `localStorage`로 재표시 억제. 영향: 이해도 +2.

**T1-2 한 명 따라가기** — §22.11 #1이자 3차 서사파·부모·개발자 공통 요청. 심 클릭 판정을 확실히 하고(2인이
패널을 못 열었다 — 툴 원인 가능성이 있으니 **먼저 실제 마우스로 재현**), *팔로우 모드*: 카메라 추적 + 그 심의
타임라인(기억·관계 변화·판단 사유). 서사파가 "관계를 반영한 대화"를 최고 장점으로 꼽았다 — 그걸 **게임의 축**으로
끌어올린다.
- 완료 기준: 팔로우 중 5분간 그 심의 사건이 타임라인에 시간순으로 쌓인다. 영향: 재미 +1.5, 조작·UI +1.

**T1-3 레버의 인과를 보이게** — 정책 변경 → 3일 뒤 *결과 카드*(세수 변화, 굶주림 건수, 지지도). §22.22 재정
검토가 있어도 못 봤던 이유가 이것이다. sim 변경 없음 — 이미 있는 이벤트를 집계해 보여준다.
- 완료 기준: 세율 변경 후 3일 내 카드 1장. 영향: 재미 +1, 그럴듯함 +0.5.

**T1-4 목표 트리** — `city_promoted`·§18 티어·§19.12 기차역 언락이 이미 있다. "인구 30 → 카페 / 장거리 수요 →
기차역"을 **보이는 트리**로. 승급 자체는 손대지 않는다(창발 유지).
- 영향: 재미 +1, 이해도 +0.5.

Tier 1 예상: 재미 5.2→8.7, 이해도 6.3→8.8, 조작·UI 7.3→8.3, 그럴듯함 7.4→7.9. **평균 ≈ 7.9, ★4.0 목표.**

## 4. Tier 2: 세계가 설명되게

**T2-1 판단 사유 노출** — README가 약속했는데(§22.11 #4) 패널에 없다. 심의 `plan`·마지막 선택 점수 상위 3개를

**T2-2 초기 경제(Codex 합의 필요)** — Day 0 국고 0 + 공무원 임금 → 첫날부터 적자. 5인 전원 목격, 장르팬 "첫날부터

*이야기*가 되게 한다. 이미 PLAN에 있는 과제다.

**T2-3 대화 반복 억제** — 같은 대사가 15~30분 간격으로 재등장, "공원 모임 얘기"를 서로에게 되돌려 말함. 제안:

**T2-4 모임 0명 참석** — 공지 전 소문 3회, 당일 0명, 공지자 본인도 공사 돕기. sim 조사(초대 이행 §22.6 vs
construct 우선순위). Codex 합의.

Tier 2 예상: 그럴듯함 →8.9, 재미 →9.0.

## 6. 검증 게이트

- 각 Tier 종료마다 **같은 5인 페르소나**로 재검증(`deepsims-playtest-5` 워크플로 재사용). 게이트: Tier0 ★3.5 /
  Tier1 ★4.0·평균 7+ / Tier3 평균 9.
- **테스터 도구 문제를 먼저 푼다**: 5인 전원의 마우스 좌표가 4.46~8.75배 어긋나 JS 합성 이벤트로 조작했다. 이걸
  두면 조작·UI 점수가 도구 탓에 눌리고 "심 패널 안 열림"이 영원히 미확정이다.
- 상위 버그는 계속 **반박 검증**(confirmed만 고친다).

## 7. 하지 말 것

- 점수를 올리려고 지표를 만지지 않는다(§0.1). 적자·굶주림은 숨기지 않고 **설명**한다.
- Tier 0 전에 Tier 1·2를 하지 않는다 — 창이 거짓말하는 동안의 기능은 검증 불가다.
- 결정성 계약 위반 금지. 클라의 모든 선택은 tick 결정적, `sim/` 변경은 Codex 합의 + 해시·리플레이 테스트.

## 8. Opus 구현 지시 형식

각 항목을 하나의 작업 단위로: (1) 파일·함수, (2) 완료 기준 — 숫자로, (3) 회귀 테스트 — 고치기 전 상태에서
**실제로 실패하는지** 확인, (4) 예상 점수 영향, (5) 파괴적 검증 전 커밋(§22.37·§22.39 사고).
