## 최소 공공 셔틀 (schema74/logic83)

연결 가능한 역의 결정적 인접 타일 경로, 노선당 왕복 열차1대, 도보 접근/이탈,
실제 대기·유한 정원·승하차를 구현했다. 기존 시설과 공터/회전 대학 예약은 회피한다.
물은 다리 없이 통과하지 않으며, 새 다리로 기존의 분리된 역 그룹도 연결할 수 있다.
경로 차단 시 열차 위치와 시간표 진행을 함께 멈추고 승객은 현재 위치에서 목적지까지
다시 길을 찾는다. 복구 시 정지한 시간표에서 재개한다. 선로 overlay는 건설로 덮을 수 없다.

기본4칸/tick·역 정차10tick·정원8명은 개통 시 노선에 저장한다. 무료 공공 기반시설로
건설비에 포함하며 별도 운영비/연료/직원/운임은 없다. 노선 환승·신호·충돌·혼잡도 없다.
한 번의 열차 구간만 선택하며 도보/차보다 예상 시간이 짧을 때만 사용한다. 예상에는
시간표 대기가 포함되지만 정원 경쟁은 포함되지 않아 실제 시간 단축을 보장하지 않는다.

`world.rail.stats.boardings/alightings`는 실제 승하차다. passengerTiles/Ticks는 실제
차량 이동에 참여한 승객 합계다. waitingTicks는 승차 처리 직전 대기 상태였던 tick 합이며
즉시 승차도1회 포함한다(승차 이벤트의 경과 waitTicks는0일 수 있다). transportStats의
railTrips/railArrivals는 철도를 선택한 여정의 출발/최종 도착으로, 운행 취소 후 도보

최종 목적 시설 자원 도착에서만 집계한다. 차량 이동과 철도 이동 통계는 구분한다.

회귀는 유한 정원, 명령 중단 거부, 차단/재개, 회전 대학 예약, 다리 연결, 저장 이관,

## 기존 계측 도입 이력

관측 전용 schema61, 로직 v57 유지. `transportStats.today`는 진행 중인 날,
`history`는 완료된 최근 14일이다. `statsHistory[].transport`는 전날 요약이며 중첩된
`day`가 실제 계측 날짜다. OD는 목적·32칸 격자 출발/도착·차량 여부 키로 집계한다.
차량 여부는 기존 이동 규칙의 `hasCar`와 같은 뜻이며, 도로·주차 선택을 새로 만들지 않는다.

`walkingTicks`는 그 날 실제 전진에 사용한 tick 수다(차량의 여러 칸 전진도 tick당 1).
`completedWalkingTicks`는 그 날 도착한 전체 관측 여정의 소요 tick 합이다. 자정을 넘는
여정은 두 값의 집계 구간이 다르다. 구 세이브의 출발 미관측 여정은 `partialArrivals`로
구분하며 평균 완료 시간에 섞지 않는다. 경로 길이 0인 행동 시작도 출발 수와 별도다.
