# #93 주택시장 검증

schema60/logic56. 서비스 종류별 최근접 시설 거리와 전날 완료 이용 횟수만으로 정수 지가를
계산한다. RNG, 주민 상태, 시설 상태를 읽는 과정에서 변경하지 않는다. 호가는 기본 임대료,
지가 비율, 실제 침대 수의 합이며 빈집도 매일 스냅샷에 남는다.

입주 가구별 청구액은 집 호가를 입주 가구 수로 나눈 올림값이다. 가구원의 현금에서만 ID가
안정된 순서로 걷고, 실제 생존 소유자 또는 국고에 같은 금액을 더한다. 부분 지급은 부족액을
남긴다. 3일 임대 부담 뒤에는 더 싸고 전원이 들어갈 빈집 하나를 선점하며, 다음 tick에 구성원,
기존 집, 목표 공실·침대, 현재 가격을 다시 확인한다. 실패하면 이동하지 않는다.

집중 검사는 지가 함수의 순수성·정수성, 공공/민간 수취자의 총량 보존과 부분 지급, 내구 이사
의도의 다음-tick 성공/실패, RNG draw를 소비하지 않는 v59 이관을 다룬다. 전체 회귀 테스트는
389/389, 프로덕션 빌드는 통과했다.

## 고정 시드 30일 A/B

seed9300, 입력 없이 43,200틱을 각각 실행했다. 대조군은 지가 관측과 정산 순서를 유지하되
`baseRent/landRentPct/bedRent=0`으로 실제 청구만 0으로 만들었다.

임대료가 실제 압박과 이사를 만들었지만 굶주림도 늘었다. 두 세계는 선택 이후 RNG 소비 경로가
갈리므로 인구·국고 차이를 임대료의 단일 직접 효과로 해석하지 않는다. 기본값이 모든 지표를
개선했다고 주장하거나 결과를 맞추기 위해 돈·인구·주택을 주입하지 않는다. 마지막 날 시장
스냅샷은 15개 집, 청구2,182원, 납부1,908원, 부족274원을 기록했다.
