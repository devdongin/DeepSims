# #96 학제 구현 중 체크포인트

현재 브랜치: `codex/96-school-system`. 아래는 **완료 보고가 아닌 구현 상태**다.

## 작성·검증한 핵심 규칙

- `sim/education.js`: 초7~12, 중13~15, 고16~18, 대학19~22는 진학 선택 후에만.
- 대학 선호는 현재 지능·SN·JP의 연속 가중. seed/id/연도 의사확률, world RNG 미소비.
- 대학이 없거나 본인+동거 부모의 학비가 부족하면 보류. 취업 선택은 매일 다시 추첨하지 않음.
- 학비는 본인 → 부모id 순서로 차감하고 같은 금액을 국고에 입금. 부족하면 부분 청구하지 않음.
- 학교 종류가 맞는 실제 학업 틱만 과목 단계별 출석에 기록. 23세 이후 대학 학업량으로 학위 판정.
- 단위 검사4개 통과. 이 모듈은 아직 tick에 연결하지 않았음.

## 남은 통합 (이 파일이나 검사 통과로 완료를 대신하지 않음)

1. 기본 education 상태/파라미터/검증 및 저장 마이그레이션. 기존 과거 학업량을 조작하지 않음.
2. 초·중·고 시설을 별도 타입으로 생성/구역 지정/공사할 수 있게 하고 teacher 근무·공공 회계·산업 P에 연결.
3. 기존 school 이관. 시설 id/좌표/자원/예약을 보존하고 유형 변경 인덱스 캐시를 안전하게 갱신.
4. 학생은 실제 study 행동으로 올바른 학교에 등교, 근무 임금을 학교 출석 보상으로 받지 않음.
5. 7세 입학·13/16세 진급·19세 선택·23세 대학 종료를 생애 파이프라인과 연결. 졸업 직업 선택 드로우 변경을 명시.
6. 등교 희망 수요/교실 부족을 실제 학교 건설로 연결. 빈 학교를 인구 조작이나 사전 설치로 만들어 해결하지 않음.
7. 화면에 학교 이름/학업/학비/졸업/학위와 건설 메뉴 표시, 관련 계약 검사 확장.
8. 전체 회귀·이벤트 저장·HTTP·실제 등교·고정 스냅샷 A/B 및 별도 브라우저 확인.
9. 학교별 4방향+내부 에셋. 2026-09-03 내장 imagegen 호출은 HTTP404로 실패했음.
   CLI/API 전환은 사용자 승인 전에는 하지 않음. 임시 아트로 학교 완료를 주장하지 않음.
