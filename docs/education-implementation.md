# #96 학제 구현 중 체크포인트

현재 브랜치: `codex/96-school-system`. 아래는 **완료 보고가 아닌 구현 상태**다.

## 작성·검증한 핵심 규칙

- `sim/education.js`: 초7~12, 중13~15, 고16~18, 대학19세 이후 진학 선택. 학부4년/석사2년/박사4년은 최소 수학 기간이며 실제 출석도 필요하다.
- 대학 선호는 현재 지능·SN·JP의 연속 가중. seed/id/연도 의사확률, world RNG 미소비.
- 대학이 없거나 본인+동거 부모의 학비가 부족하면 보류. 취업 선택은 매일 다시 추첨하지 않음.
- 학비는 본인 → 부모id 순서로 차감하고 같은 금액을 국고에 입금. 부족하면 부분 청구하지 않음.
- 학교 종류가 맞는 실제 학업 틱만 과정별 출석에 기록. 대학원 진학 시 이전 과정 출석을 복제하지 않는다.
- 사용자2026-09-04 추가 지시: 비진학자는19세부터, 학부/석사/박사 중 최종 선택 과정 졸업 후에만 근무한다. 나이만으로 자동 취업하지 않는다.
- tick의 일일 생애 전환·수행·후보 선택·계획·건설까지 연결했다.
- 접근할 수 없는 대학에는 등록금을 내지 않는다. 기존 저장의 학생 근무도 정산 전에 중단한다.
