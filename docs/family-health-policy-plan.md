# #71 육아·건강 정책 구현 계약 (착수)

기준 main b24c7ff. 학교/대학원·학생 무근로(#96), 공공 식사(#57), 공공 시설 매출
국고 환류는 이미 존재한다. 이를 중복하거나 학생에게 임금을 만들어 주지 않는다.

## 확인한 현재 경로

- 내구 `policy` 입력은 taxPct/welfareAmount/welfareThreshold만 허용한다.
- `see_doctor`는 800원 전액 개인 부담이며 child는 행동 자체가 차단된다.
- 완료 시 자금/진료 위치 재검증 없이 돈을 차감하고 회복한다.
- `world.parents`에 부모 관계가 있다. 동일 homeId만으로 모든 동거인을 부모 취급하면 안 된다.
- 병원 수입은 일일 `public_revenue_remitted`로 국고에 돌아온다.
  보조금을 병원으로 보냈다가 환류한 총액을 순재정 지출로 과장해서는 안 된다.

## 구현 순서와 완료 조건

1. 건강 자기부담률을 내구 정책에 추가한다. 기본100%(기존 가격 유지), 정수0~100.
   정책·개인/보호자 자금·국고를 기반으로 실제 완료 시 원자적으로 정산한다.
   부족 예산/자금/취소/잘못된 장소는 음수 잔액이나 무료 치료를 만들지 않는다.
   총 진료비=환자측 부담+공공 부담, 병원 원장으로 이전한다. 총 이전과 순국고 변화를 따로 관찰한다.
2. 부모의 실재 관계/동거/생존을 확인한 가구 지원을 추가한다. 내구 입력과 일일 지급 원장을
   연결하고 같은 아이의 중복 수급, 룸메이트 수급, 사망/이사 후 낡은 수급을 막는다.
3. 실제 육아 행동 및 아동 진료 이동 경로를 만든다. 아동에게 일을 주거나 원격으로
   치료하지 않는다. 보호자와 아동의 위치·이동·취소·예약을 명시하고 부모의 노동시간과
   돌봄시간을 관측한다. 구현 완료: 보호자가 아이 위치까지 이동한 뒤 병원 자리를 아이
   명의로 예약하고 같은 경로를 동행하며30틱 진료를 마친다. 보호자 부재 시 둘 다 해제한다.
4. 시장 UI에 정책 값/지출을 표시하고 기존 입력 검증과 같은 권위를 사용한다.
5. 스키마·로직 버전, 기존 저장·진행 중 행동·내구 입력 재생·분할 실행을 검증한다.
   학생/미성년/미졸업자의 노동 차단 회귀를 유지한다.
6. 고정 스냅샷7/30일 정책 전후 비교: 아픈 채 지낸 sim-ticks, 실제 진료/의사 회복,
   자기부담/공공부담/순국고, 아동 가구 소득·돌봄·노동시간, 출생, 인당 비용.
   입력 인구·자금은 조작하지 않으며 모든 지표 개선을 요구하거나 수치를 눌러 맞추지 않는다.
