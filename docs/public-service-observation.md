# #88 경찰·소방 관측: #154 정원 판단의 선행 자료

상태: 설계 중. 기존 후보·경로·RNG·정원·보수·평판 규칙은 바꾸지 않는다.
기존 시설 수요 원장의 O=0을 임의 값으로 채우지 않는다.

## 대상 선택과 판정

- 경찰은 실제 고용주의 관할, 시설 배열 순서, patrolIdx와 문 주변 N/S/E/W/문
  순서를 그대로 공유하는 목표 조회 함수를 후보 생성과 관측이 함께 사용한다.
- 소방은 기존 incidents 배열 순서와 firesite 좌표를 공유한다. 현재 후보가 경로
  실패 쿨다운을 검사하지 않으므로 관측만 이를 새 자격 조건으로 만들지 않는다.
- 사전 판정은 자격/근무시간을 먼저 통과한 실제 행동에 한한다. 대상 없음,
  가상 지점 예약됨, 걸을 수 있는 순찰 지점 없음/기존 쿨다운을 구분한다.
  도달 가능성을 보려고 새 BFS를 실행하지 않는다. 실제 시작의 no_path는 별도 계측한다.
- 빈 경찰서 좌석은 예약된 순찰 지점의 대체 자원이 아니다. 화재가 없다는 것은
  소방서가 없다는 뜻도, 소방 인력이 부족하다는 뜻도 아니다.

## 원장

- patrol/fire를 구분하고 기존 산업 시설 부재·만석 수요와 별개로 저장한다.
- 사전 부족 신호는 주민/서비스/사유/하루당 한 번. 실제 경로 시도·시작·완료·
  경로 실패는 실제 호출/이벤트 횟수다. 둘의 단위가 다름을 공개 요약에 명시한다.
- 현재 날과 직전13일만 보관한다. 공개 요약에는 중복 제거용 주민 ID를 보내지 않는다.
- 일 완료/화재 진압/평판 변화는 서로 다른 사실이다. 다른 원인으로 꺼진 화재에
  늦게 도착하여 action_completed가 나와도 진압 성공으로 집계하지 않는다.
- 이 원장은 정원·산업 언락·건설·주민 행동에서 읽지 않는다. #154는 후속 문제다.

## 검증 게이트

공유 조회 전후 후보 전체와 경로/이벤트 해시 일치, 예약자 본인/타인,
목표 없음/고립된 문/쿨다운/근무시간 밖/미성년/학생/다른 직업, 실제 실패와 성공,
자연 소화와 진압 구분, 하루 중복 제거/14일 만료/중간 저장 재개,
snapshot/batch 요약 일치와 주민 ID 비노출을 검증한다.
계측 상태 때문에 세계 해시가 달라지는 것은 문서화하되 RNG/선택 변화는 허용하지 않는다.
